# Changelog

## 2.1.0

- Added an optional loopback-only PyMuPDF engine.
- Added searchable source-text replacement using redaction and page-content insertion.
- Added native AcroForm inspection and field updates.
- Added signature detection and mutation blocking for signed PDFs.
- Added in-memory restoration for native source revisions.
- Added browser-only fallback mode and native engine status UI.
- Added Python and HTTP integration tests to CI.
